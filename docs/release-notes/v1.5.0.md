# Office PDF Binder v1.5.0

[日本語](#user-content-japanese)

## English

### Changes

- Added one entry to the Windows 11 context menu, replacing the legacy menu. Selected files are sent together, including when the application is already running, with improved reception, queuing, and foreground activation.
- Changed the installer to current-user installation only, without administrator privileges. Uninstall now cleans up the menu package and certificates installed by the application.
- Preserved bookmark hierarchies during editing and export, including deletion of all bookmarks. Added multiple selection and bulk deletion with Undo support.
- When pages move, root bookmark groups follow their destination pages while child bookmark order and hierarchy are preserved.
- Fixed internal PDF links after page reordering, image rotation and SVG export, and multi-frame image bookmarks.
- Fixed duplicate paths within one addition request, Undo after interrupted additions, header/footer settings in Undo, and configuration values containing percent signs.
- Excluded the output directory from batch input. If a source PDF loses pages after loading, saving fails without replacing the existing output.
- After successfully overwriting an input file, the page list and history are cleared with an explanation to prevent reuse of stale input state.

### Installation and downloads

- `OfficePDFBinder_Setup_1.5.0.exe`: current-user installer.
- `OfficePDFBinder_Portable_1.5.0.zip`: portable edition.
- Remove an older all-users installation before installing this version.
- Explorer integration uses a self-signed sparse package and is available on Windows 11. No legacy menu is installed on Windows 10. The application executables themselves remain unsigned.
- Uninstall removes certificates recorded as installed by this application when its package is no longer present. Pre-existing certificates are preserved.

### Validation and remaining checks

- Manual checks of the preceding build were generally successful. The final 1.5.0 artifacts still require build and installation checks.
- Explorer's context menu may briefly resize when it opens. This behavior remains under observation.

## 日本語

### 変更点

- Windows 11の右クリックメニューに1項目を表示し、従来メニューを廃止しました。選択した複数ファイルをまとめて渡し、アプリ起動中の追加処理と前面化も改善しました。
- インストールを管理者権限不要の「現在のユーザーのみ」に統一しました。アンインストール時には、アプリが導入したメニュー用パッケージと証明書を片付けます。
- しおりの階層を編集・保存時に保持し、全削除を保存結果へ反映するようにしました。複数選択による一括削除と「元に戻す」に対応しました。
- ページ移動時は、最上位のしおりを子孫ごとのまとまりで移動先ページ順に並べます。子しおりの順序と階層は保持します。
- ページ並べ替え後のPDF内部リンク、画像の回転とSVG書き出し、複数フレーム画像のしおりを修正しました。
- 一度の追加要求内の重複パス、中止後の追加に対する「元に戻す」、ヘッダー・フッター設定の履歴、パーセント記号を含む設定値を修正しました。
- 一括処理で出力フォルダーを入力から除外します。読み込み後に元PDFのページが減った場合は保存を中止し、既存の保存先を保護します。
- 入力ファイルへの上書き保存に成功した場合は、古い読み込み状態を再利用しないよう、理由を通知して一覧と履歴をクリアします。

### インストールと配布ファイル

- `OfficePDFBinder_Setup_1.5.0.exe`：現在のユーザー向けインストーラー。
- `OfficePDFBinder_Portable_1.5.0.zip`：ポータブル版。
- 以前の全ユーザー向けインストールがある場合は、先にアンインストールしてください。
- 右クリック連携は自己署名したSparse Packageを使用し、Windows 11で利用できます。Windows 10には従来メニューを登録しません。アプリの実行ファイル自体は未署名です。
- アンインストール時は、パッケージが残っていないことを確認して、アプリ自身が導入したと記録された証明書を削除します。以前から存在する証明書は保持します。

### 検証状況と残る確認

- 直前のビルドに対する手動確認は概ね成功しています。最終的な1.5.0の成果物については、ビルドとインストール後の確認が必要です。
- エクスプローラーの右クリックメニューが表示時に一瞬伸縮する場合があります。この現象は継続確認とします。
