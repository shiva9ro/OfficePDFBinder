# Office PDF Binder v1.5.3

[日本語](#user-content-japanese)

## English

- Added the missing `unvirtualizedResources` capability to the Windows 11 context-menu package manifest for both x64 and ARM64. This addresses registration failures reporting that the capability is required for a package with external location.
- PDF processing and C++ shell integration code are unchanged from v1.5.2.

### Downloads

- `OfficePDFBinder_Setup_1.5.3.exe`: current-user installer.
- `OfficePDFBinder_Portable_1.5.3.zip`: portable edition.

<a id="japanese"></a>
## 日本語

- Windows 11の右クリック用パッケージのマニフェストに、不足していた `unvirtualizedResources` を追加しました。x64・ARM64の両方が対象です。外部配置パッケージに必要な宣言がないとして登録に失敗する問題への対応です。
- PDF処理およびC++の右クリック連携コードは1.5.2から変更していません。

### ダウンロード

- `OfficePDFBinder_Setup_1.5.3.exe`：現在のユーザー向けインストーラー。
- `OfficePDFBinder_Portable_1.5.3.zip`：ポータブル版。
