# Office PDF Binder v1.4.1

Release date: August 15, 2026

[日本語](#user-content-japanese)

## English

### Highlights

- Strengthened Microsoft Office conversion safety by forcing macros off while
  documents are opened for PDF conversion.
- Prevented Word and Excel external links from being updated during conversion,
  so the PDF uses the values already saved in the source document.
- Opened Office documents read-only and explicitly discarded any conversion-time
  changes without overwriting the source document.
- Protected existing output PDFs by generating a temporary PDF in the destination
  folder and replacing the existing file only after PyMuPDF has closed it. This
  behavior is shared by regular GUI saves, selected-page export, and batch output.
- Improved stopping during background work. The progress dialog's close button,
  Stop button, and Esc key now request a safe stop while keeping the
  dialog visible until Office, LibreOffice, PDF, and temporary-file cleanup and
  the worker itself have fully finished.
- Added CI detection for Qt translation catalogs that are out of sync with source
  strings.
- Updated GUI tests and translation baselines for the v1.4 interface.

### Downloads

- `OfficePDFBinder_Setup_1.4.1.exe`: Windows installer
- `OfficePDFBinder_Portable_1.4.1.zip`: Portable edition

### Notes

- Office document conversion requires either Microsoft Office or LibreOffice.
- Microsoft Office macros are disabled for automated conversion. Word and Excel
  external links are not refreshed; the PDF reflects values saved in the source.
- Replacing an existing PDF requires permission to create, delete, and rename files
  in the destination folder. If replacement fails, the existing PDF is preserved.
- If Office or LibreOffice stops responding, application shutdown waits for the
  conversion call to return so cleanup can complete safely.
- The distributed executables are currently unsigned. Windows SmartScreen or
  antivirus software may display a warning.

## 日本語

### 主な変更点

- Microsoft OfficeによるPDF変換時にマクロを強制的に無効化し、Office文書を
  より安全に開くようにしました。
- WordとExcelの外部リンクを更新せず、元文書に保存されている値を使って
  PDF化するようにしました。
- Office文書を読み取り専用で開き、変換中の変更を保存せず破棄することで、
  元文書を上書きしないことを明確にしました。
- 既存PDFを上書きする場合、保存先フォルダーに一時PDFを作成し、PyMuPDFが
  ファイルを閉じた後にだけ既存PDFと置き換えるようにしました。通常GUI保存、
  選択ページの書き出し、一括処理で同じ保存処理を使用します。
- バックグラウンド処理中の中止を安全にしました。進捗ダイアログの×、
  中止ボタン、Escキーはいずれも中止を要求し、Office、LibreOffice、PDF、
  一時ファイルの後始末とワーカーの完全な終了までダイアログを表示します。
- ソースの表示文言とQt翻訳カタログの同期漏れをCIで検出するようにしました。
- v1.4の画面文言に合わせてGUIテストと翻訳基準を更新しました。

### ダウンロード

- `OfficePDFBinder_Setup_1.4.1.exe`：Windowsインストーラー
- `OfficePDFBinder_Portable_1.4.1.zip`：ポータブル版

### 注意事項

- Office文書の変換には、Microsoft OfficeまたはLibreOfficeのどちらかが必要です。
- Microsoft Officeの自動変換ではマクロを無効化します。WordとExcelの外部リンクは
  更新せず、元文書に保存済みの値をPDFへ反映します。
- 既存PDFの置換には、保存先フォルダーでファイルの作成、削除、名前変更ができる
  権限が必要です。置換に失敗した場合、既存PDFは保持されます。
- OfficeまたはLibreOfficeが応答しなくなった場合、後始末を安全に完了するため、
  変換処理から制御が戻るまでアプリの終了を待ちます。
- 配布する実行ファイルには現在コード署名がありません。Windows SmartScreenや
  ウイルス対策ソフトが警告を表示する場合があります。
