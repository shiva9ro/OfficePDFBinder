# Office PDF Binder v1.5.2

[日本語](#user-content-japanese)

## English

Based on v1.5.1, with certificate registration and uninstall cleanup fixes. The existing editing and Windows 11 integration improvements are retained.

- Added Windows 11 context-menu integration for opening selected files together, including when the application is already running. It replaces the legacy menu; Windows 10 has no Explorer menu integration.
- Preserved bookmark hierarchies during editing and export, added bulk bookmark deletion with Undo, and fixed PDF links after page reordering, image rotation, SVG export, and interrupted additions.
- Installs the application for the current user, while trusting the Windows 11 context-menu certificate machine-wide with UAC approval. The certificate is kept while another user's package remains.
- Certificate query or cleanup failures, including declined UAC approval, no longer block application removal. Failure to remove the context-menu package itself still stops uninstallation.

- Shortened the hold before moving pages to 350 milliseconds. Small diagonal pointer movements are now tolerated, and an open-hand cursor indicates when the pages are ready to move.
- Preserved range selection when the pointer moves beyond the threshold before the hold completes, and restored the normal cursor when the operation ends.
- Fixed the native build to select the compiler explicitly for each CPU architecture. Build-time checks now reject EXE/DLL files with an incorrect architecture.
- Extended CI to build and check both x64 and ARM64 context-menu DLLs and packages, including the ARM64 context-menu fix.

### Downloads

- `OfficePDFBinder_Setup_1.5.2.exe`: current-user installer.
- `OfficePDFBinder_Portable_1.5.2.zip`: portable edition.

## 日本語

1.5.1を基に、証明書登録とアンインストール時の後片付けを修正しました。既存の編集機能・Windows 11連携の改善を引き継ぎます。

- Windows 11の右クリックメニューから、選択したファイルをまとめて追加できます。アプリ起動中の追加にも対応します。従来メニューは廃止し、Windows 10には右クリック項目を登録しません。
- しおりの階層保持、一括削除と「元に戻す」、ページ並べ替え後のPDF内部リンク、画像回転、SVG書き出し、中止後の追加処理を改善しました。
- 本体は現在のユーザー向けにインストールし、Windows 11の右クリック用証明書はUACによる確認を経てPC全体へ登録します。別ユーザーのパッケージが残っていれば証明書は保持します。
- 証明書の照会・削除の失敗やUAC拒否でも、本体のアンインストールを続行します。右クリック用パッケージ自体の解除失敗では引き続き中止します。

- ページ移動の長押し時間を350ミリ秒に短縮しました。斜めの小さな手ぶれを許容し、移動できる状態になるとカーソルが開いた手に変わります。
- 長押し成立前に一定距離を動かした場合は、従来どおり範囲選択になります。操作終了時は通常のカーソルに戻ります。
- CPUごとにコンパイラーを明示指定するようビルド処理を修正しました。生成したEXE・DLLのCPU形式が指定と異なる場合は、ビルドを停止します。
- CIでx64・ARM64両方の右クリック用DLLとパッケージを作成・検査します。ARM64環境で右クリックメニューが表示されない問題の修正を含みます。
